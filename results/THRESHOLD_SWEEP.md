# Threshold sweep (H4)

Pseudo-threshold = the p where the k=2 (d=5) MWPM curve stops
beating the k=1 (d=3) curve (linear interpolation between bracketing swept p values;
'not found in range' if the curves never cross within the sweep).

| observable_kind | decoder | pseudo-threshold p |
|---|---|---|
| spacelike | mwpm | 0.00334 |
| spacelike | gnn | 0.01489 |
| timelike | mwpm | 0.00304 |
| timelike | gnn | not found in swept range |
